
# Customer Churn Analysis

## Project Overview
This project analyzes customer churn patterns to identify the key factors contributing to customer attrition.

## Dashboard KPIs
- Total Customers: 7,043
- Churned Customers: 1,869
- Churn Rate: 26.54%
- Average Monthly Charges: $64.76

## Analysis Performed
- Contract Type Analysis
- Tenure Group Analysis
- Payment Method Analysis
- Internet Service Analysis
- Tech Support Analysis
- Online Security Analysis
- Paperless Billing Analysis

## Key Business Insights
- Month-to-month contract customers have the highest churn rate (42.71%).
- Fiber optic customers have a churn rate of 41.89%.
- Customers without tech support have a churn rate of 41.64%.
- Customers without online security have a churn rate of 41.77%.
